# Tsunamis — final website

Static Vercel-ready website for the Environmental Studies project.

Changes in this version:
- Added National Geographic “Tsunamis 101” YouTube embed below the preparedness section, muted by default.
- Replaced the state/district explorer with a city-focused India map featuring five selected coastal cities: Port Blair, Chennai, Nagapattinam, Mumbai and Visakhapatnam.
- City markers open documented tsunami history and preparedness information.
- No artificial risk score is used.
- The map does not use OpenStreetMap tiles, avoiding the previous 403 tile-blocking problem.
- Kept the light, elegant visual theme, modern tsunami event cards, preparedness section, sources and LPU acknowledgement.


Latest fixes: LPU logo is embedded directly in index.html so it cannot break from a missing asset; the National Geographic video uses the standard YouTube embed URL with mute enabled and a YouTube fallback button.
